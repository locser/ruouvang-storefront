# Dữ liệu danh mục

Kèm danh mục công khai đã được crawler lưu, phục vụ unit test và seed môi trường mới; không kèm dữ liệu khách hàng hoặc bản sao database. Có thể chạy `node scripts/scrapers/crawl-cwwines.js` từ thư mục website để cập nhật danh mục công khai trước khi seed. Ảnh giao diện và nội dung tĩnh đang dùng đã nằm trong storefront. Kiểm tra quyền sử dụng nội dung trước khi phát hành tên miền mới.
